# Tic-Tac-Toe Game
A simple, interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features
- 3x3 grid board
- Player turn indicator
- Win and draw detection
- Restart button
## How to Run
1. Open `index.html` in any browser.
2. Play the game locally.
